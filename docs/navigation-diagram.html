Pastabos / prielaidos

  • Diagrama rodo tik React page/view boundary klases ir navigaciją. Controller, service, model ir DB klasės sąmoningai nerodomos.
  • PlotCreatePage vidiniai žingsniai boundary, zones, summary nėra atskiros boundary klasės, nes jie realizuoti state kintamuoju tame pačiame komponente.
  • PlotDetailPage vidiniai režimai zones ir boundary, taip pat layer / inspector panelės, nėra atskiri puslapiai.
  • PlantsPage katalogo ir pasodintų augalų režimai parodyti kaip to paties boundary pastaba, nes jie keičiami per view query/state, o ne per atskirą UI page.
  • CatalogPlantsPage įtrauktas kaip redirect boundary, nes route ir komponentas egzistuoja, bet jis nerodo savarankiško UI.
  • PDF eksportas iš PlotDetailPage yra failo atsisiuntimo veiksmas per api.downloadPlotPdf(), todėl nevaizduotas kaip atskiras boundary.
  • Bendruomenės įrašo kūrimo dialogas, kalendoriaus dienos drawer, inventoriaus edit/add forma ir admin user detail panelė nėra atskiri page komponentai.
