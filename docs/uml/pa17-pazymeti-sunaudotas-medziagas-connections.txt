- InventoryItem — «entity»; source: backend/app/Models/InventoryItem.php

Routes and API helpers used for audit only, not shown as lifelines:
- backend/routes/api.php: GET /calendars/{calendar}/tasks; PATCH /tasks/{task}/complete; inventory routes are present but PA17 consumption does not use InventoryController as the main flow.
- frontend/src/lib/api.js: listCalendarTasks(calendarId, params); completeTask(taskId, payload); apiClient is intentionally hidden.
- frontend/src/App.jsx: calendar and inventory routes are not shown as lifelines.
