7 sistemos klasių modeliai pagal loginę architektūrą

Diagramos sugrupuotos į tuos pačius pagrindinius posistemius kaip atnaujintoje loginėje architektūroje: User, Admin, Calendar, Plot, Plant, Inventory ir Community. Kiekviename faile rodoma reali React Page / boundary -> Laravel Controller -> Service -> Eloquent Model grandinė pagal codebase.

User posistemio sistemos klasių modelisAutentifikacija, registracija, paskyra, sesija ir slaptažodžio atkūrimas. Admin posistemio sistemos klasių modelisAdministratoriaus vartotojų valdymas ir audito įrašai. Calendar posistemio sistemos klasių modelisRekomendacinis kalendorius, užduotys, orai ir inventoriaus padengimas. Plot posistemio sistemos klasių modelisSklypai, zonos, workspace, istorija, bendrinimas, rotacija, derlius, analitika ir PDF eksportas. Plant posistemio sistemos klasių modelisAugalai, katalogas, priežiūros profilis, Perenual ir būklės istorija. Inventory posistemio sistemos klasių modelisInventoriaus CRUD, kalendoriaus resursų poreikiai ir naudojimo istorija. Community posistemio sistemos klasių modelisBendruomenės įrašų srautas, sklypo feed ir įrašų valdymas.
