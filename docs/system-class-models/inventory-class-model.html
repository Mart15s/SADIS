Inventory posistemio sistemos klasių modelis

Inventory posistemis pagal loginę architektūrą turi vieną pagrindinį InventoryPage boundary. Add/Edit/Delete nėra atskiri puslapiai, todėl jie rodomi kaip InventoryPage operacijos. Inventorius codebase siejamas su GardenOwner, o ryšys su kalendoriumi vyksta per TaskResourceRequirement ir InventoryUsageLog.

Ryšių ir operacijų sąrašas

Nr.Iš kurios klasėsĮ kurią klasęOperacija / metodas / ryšysRyšio tipasPastaba
1 InventoryPage InventoryController api.listInventory() -> index(request) REST request GET /api/inventory
2 InventoryPage InventoryController api.getInventoryItem(itemId) -> show(request, item) REST request GET /api/inventory/{inventoryItem}
3 InventoryPage InventoryController api.createInventoryItem(payload) -> store(request) REST request POST /api/inventory
4 InventoryPage InventoryController api.updateInventoryItem(itemId, payload) -> update(request, item) REST request PATCH /api/inventory/{inventoryItem}
5 InventoryPage InventoryController api.deleteInventoryItem(itemId) -> destroy(request, item) REST request DELETE /api/inventory/{inventoryItem}
6 InventoryController InventoryService listForOwner(), createForOwner(), updateForOwner(), deleteForOwner() service call Controlleris tik išsprendžia savininką ir validuoja duomenis.
7 InventoryService InventoryItem query/create/update/delete item ORM access Inventoriaus įrašai priklauso savininkui.
8 InventoryService GardenOwner owner inventoryItems / ownedInventoryItems ORM access Reali realizacija sieja inventorių su GardenOwner.
9 InventoryService TaskResourceRequirement read requiredResources for task ORM access Kalendoriaus užduočių poreikiai tikrinami pagal inventorių.
10 InventoryService InventoryUsageLog create usage logs on consume/replenish ORM access Naudojimo istorija fiksuoja kiekių pokytį.
11 TaskInventoryCoverageService InventoryItem matchingItems(), buildPlanningLedger() ORM access Generuojant kalendorių skaičiuojamas padengimas.
12 Task TaskResourceRequirement 1 *-- 0..* requiredResources() composition Užduotis turi resursų poreikius.
13 InventoryItem InventoryUsageLog 1 -> 0..* usageLogs() association Sunaudojimas siejamas su inventoriaus įrašu.
14 TaskResourceRequirement InventoryUsageLog 1 -> 0..* usageLogs() association Panaudojimas gali būti susietas su poreikiu.
15 GardenOwner InventoryItem 1 -> 0..* ownedInventoryItems() association Pastaba: tiesioginis Plot -> InventoryItem ryšys codebase nerastas.
