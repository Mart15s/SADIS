Calendar posistemio sistemos klasių modelis

Calendar posistemis apima rekomendacinio kalendoriaus generavimą, užduočių sąrašą, užduočių užbaigimą / atmetimą, Meteo.lt orų integraciją ir inventoriaus resursų padengimą. Orų integracijos atskiras produkcinis controlleris codebase neegzistuoja, nes ji naudojama CalendarGenerationService viduje. Meteo.lt rodoma kaip išorinė sistema, o WeatherForecast yra Eloquent cache / istorijos modelis.
