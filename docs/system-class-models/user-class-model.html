User posistemio sistemos klasių modelis

User posistemis apima svečio registracijos ir prisijungimo srautus, dabartinio vartotojo sesijos atkūrimą, paskyros redagavimą ir slaptažodžio atkūrimą. Frontend sluoksnyje tai realizuota per React puslapius ir AuthProvider boundary. Backend sluoksnyje REST užklausos nukreipiamos į Laravel controllerius, kurie naudoja AccountService ir el. pašto boundary.
