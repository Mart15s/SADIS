Plot posistemio sistemos klasių modelis

Plot posistemis pagal loginę architektūrą sujungia visą sklypo valdymo sritį: sklypų CRUD, geometrijos workspace, zonų valdymą, istorijos snapshotus, bendrinimą, rotaciją, derlių, analitiką ir PDF eksportą. Smulkesni use case posistemiai čia rodomi kaip realios klasės tame pačiame Plot pakete. Backend neinterpretuoja geometry kaip domeno logikos, tik ją validuoja, saugo ir grąžina.
