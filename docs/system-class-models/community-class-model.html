Community posistemio sistemos klasių modelis

Community posistemis turi vieną pagrindinį CommunityPage boundary ir backend CommunityController / CommunityService grandinę. CommunityPost gali būti globalus arba susietas su Plot, o matomumas priklauso nuo share reikšmės ir vartotojo prieigos prie sklypo. Plot šiame modelyje rodomas tik kaip susijęs domeno modelis, nes pati sklypo logika lieka Plot posistemyje.
