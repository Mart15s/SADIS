Plant posistemio sistemos klasių modelis

Plant posistemis pagal loginę architektūrą apima tiek konkrečius sklypuose auginamus augalus, tiek kataloginių augalų valdymą. CatalogPlantsPage codebase yra redirect į PlantsPage katalogo režimą, todėl katalogo UI rodomas kaip Plant paketo boundary. PlantCare yra reusable žinių bazė, o Perenual API naudojama tik per integracijos servisą.
