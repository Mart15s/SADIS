Legenda

  • requires/provides - sasajos naudojimas tarp React ir Laravel.
  • service call - vidinis backend kvietimas.
  • ORM / SQL - Eloquent modeliu prieiga prie PostgreSQL.
  • external API call - kreipinys i isorine sistema.
  • manifest - artefaktas realizuoja komponenta.

Pataisymų santrauka

  1. React ir Laravel sujungti per REST JSON API sąsają, ne per <<use>>.
  2. Eloquent modeliai perkelti į Laravel backend komponentą.
  3. Artefaktai pataisyti pagal realią codebase struktūrą: .jsx React šaltiniai, .js API/build failai.
  4. Ryšiai suderinti su sekų diagramų logika: boundary -> controller -> service -> model -> database.
