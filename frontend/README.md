# SADiS Frontend

React SPA skirta Laravel API `/api/*` endpointams.

## Lokalūs veiksmai

```powershell
npm install
npm run dev
```

## Patikros

```powershell
npm run lint
npm test
npm run build
```

Docker build production metu paleidžia `npm ci` ir `npm run build`, o rezultatą nukopijuoja į Laravel `public/`.
